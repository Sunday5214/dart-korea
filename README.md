# 전국 다트 여행

대한민국 지도에 다트를 던져 국내 여행지를 정하는 웹입니다.

- 여행지 77곳 · 실제 위경도로 투영한 해안선
- 바람이 상하좌우·대각선 8방향 + 맞바람/뒷바람으로 계속 랜덤 변화
- 던지면 카메라 5대(릴리스 → 옆 → 앞 → 뒤 → 착탄)가 다트를 따라갑니다
- 빌드 과정 없는 단일 HTML 파일 (외부 의존성은 Google Fonts뿐)

## 로컬에서 보기

`index.html`을 브라우저로 열면 끝입니다.

## 배포

GitHub Pages: Settings → Pages → Source를 `main` 브랜치 루트로 지정하면
`https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.
